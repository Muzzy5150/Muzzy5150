## Featured Projects

### AI Agents & Systems

- **[Ghost Ops](https://github.com/Muzzy5150/ghost-ops)** — An AI agent security and counterintelligence platform with a security research focus: behavioral analysis, memory integrity, MCP tool authorization, threat hunting, containment, and forensic evidence.
- **[ContextOS](https://github.com/Muzzy5150/ContextOS)** — A checkpoint-based context and memory runtime for long-horizon AI agents. Persists structured state so fresh workers can recover and continue complex workflows.

### Cyber Security Research

I focus on what happens when agents share evidence, combine capabilities, and act through tools—and how to keep those boundaries enforceable.

- **[FLASH0VER](https://github.com/Muzzy5150/Flash0ver)** — Runtime security research for autonomous multi-agent systems. Detects dangerous capabilities emerging through cooperation, reconstructs incidents, and explores selective containment in disposable research environments.
- **[MCP Breaker](https://github.com/Muzzy5150/mcp-breaker)** — Adversarial security testing for agents using Model Context Protocol tools. Tests prompt injection and permission boundaries, reproduces findings through clean-state replay, and verifies deterministic policy hardening against a disposable local target.

### DeFi & Developer Tools
